# 英雄技能表

## 规则

- 普通攻击：通常使用 `attack_01`；兽人骑兵使用 `attack_02`。普攻均为 0 蓝。
- 所有英雄入场蓝量为 0；随后按各自的蓝量恢复配置增长，满蓝后才能释放大招。
- 普通技能：通常使用 `attack_02`，0 蓝，只受 CD。
- 大招：以动作的 `mana_cost = 100` 判定，可复用现有攻击或功能动画；释放后清空蓝量。
- `block`、`heal` 是防御和治疗动作；召唤只由死灵法师使用 `summon` 动画。
- 动画素材不等于实战技能，只有单位 `actions` 中配置的动作才会在战斗中释放。
