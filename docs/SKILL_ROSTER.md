# 英雄技能表

## 规则

- 普通攻击：`attack_01`，0 蓝。
- 普通技能：通常使用 `attack_02`，0 蓝，只受 CD。
- 大招：使用 `attack_03` 或功能动画，满蓝 100，释放后清空蓝量。
- 有 `block` / `heal` / `summon` 的英雄分别接入格挡、治疗、召唤。
- 两个攻击动画的英雄把 `attack_02` 作为大招；一个攻击动画的英雄用 `heal` / `summon` 作为大招。
